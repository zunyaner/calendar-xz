# 2027日历·肖战

这是现有 [2027日历](https://zunyaner.github.io/calendar-2027/) 的肖战主题版：功能相同，首页换成舞台照片，名言换成他的歌词短句。主题色用应援红 `#911005`（取自生日 1991年10月5日）。每个月的日历卡片会垫一张半透明的照片，按月轮换。

这是个人非官方主题，与艺人及经纪公司无关。原来的公司日历和汪苏泷主题版都不受影响，可以同时装在桌面上，事项也是分开存放的。

本仓库里只有休班日期、农历节气、歌词短句和演唱会现场照片，**不包含任何个人待办**。你在网页里添加的事项只保存在这台手机上，不会上传。

## 在 iPhone 上使用

1. 用 **Safari** 打开：<https://zunyaner.github.io/calendar-xz/>
2. 点底部分享按钮，选「添加到主屏幕」。
3. 回到桌面，打开「2027日历·肖战」（图标简称「战日历」）。

用法与原版相同：首页有「本月」和 2027 年全年总览，点某个月进入详情，点某一天可以添加事项。月份范围是 2026 年 11 月至 2027 年 12 月。

## 订阅公司行事历

订阅内容与原版相同：

- `webcal://zunyaner.github.io/calendar-xz/company-2027.ics`
- <https://zunyaner.github.io/calendar-xz/company-2027.ics>

订阅名：膳魔师行事历 2026.11–2027。iPhone 订阅的日历常常不会弹出提醒，请以日历里的全天事件为准。

## 图片说明

首页大图和每月日历背景为个人提供的演唱会现场返图，仅供个人使用。2026 年 11 月至 2027 年 12 月各用一张，首页大图每次打开随机换一张。

## 歌词说明

每日一句摘自肖战演唱的《光点》《满足》《余年》《无羁》《曲尽陈情》，歌词对照百度百科（并与 QQ 音乐、网易云音乐、JOOX / KKBOX 公开歌词核对）。没有使用《一生有你》（原唱为水木年华）或《无恙》（并非肖战作品）。短句仅供个人欣赏。

## 如何更新已安装的主屏幕应用

关掉桌面上的图标再打开，一般就会换成新版本。如果还是旧的，用 Safari 再打开一次网页，等它加载完成后，再从主屏幕打开。以前添加的事项还在。

## 数据说明

休班与原版相同，来自膳魔师(中国)家庭制品有限公司 2027 年度行事历，以及《2026年11、12月行事历调整通知》。2027 年天数与公司公布一致：星期假日 104、国定假日 13、年度休假日 117、年休假 2、出勤日 246、年度出勤日 248。
